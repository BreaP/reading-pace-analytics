# Reading Progress & Pace Analytics Tool

A custom Python-based command-line utility built to dynamically track reading history, evaluate pacing velocity against explicit yearly targets, and deliver automated data-driven progress alerts.

## 📊 Business Logic & Data Metrics
While designed around a personal reading hobby, this project implements core data analysis workflows:
* **Target Benchmarking:** Calculates data velocity requirements dynamically based on remaining timeframes.
* **Data Ingestion:** Automates data structuring using a structured schema (Python dictionaries inside a nested collection).
* **Automated Data Alerts:** Features conditional logic to identify performance deficits relative to seasonal benchmarks.

## 🛠️ Tech Stack & Concepts Used
* **Language:** Python 3
* **Data Structures:** Lists, Dictionaries (Key-Value Pair mapping)
* **Logic:** Conditional branching (`if/else`), custom function engineering, string formatting.
